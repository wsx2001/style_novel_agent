## 更新：模型思维深度与系统提示词自定义（根据最新要求调整）

### 1. 模型思维深度

#### 1.1 等级定义

思维深度不再针对不同模型 API 提供预设映射，改为统一的六个等级，由系统内部处理具体参数映射，用户仅选择等级。

| 等级 | 说明 | 适用场景 |
|------|------|---------|
| **无** | 不施加任何思维深度控制，完全使用模型默认行为 | 用户希望完全手动控制其他参数时 |
| **自动** | 系统根据当前上下文（对话长度、知识库复杂度、指令类型）自动选择合适深度 | 默认选项，适合大多数场景 |
| **低** | 快速生成，推理少，响应快 | 快速脑暴、草稿、对话式推演 |
| **中等** | 均衡推理与速度，输出较连贯 | 常规小说续写、场景描写 |
| **高** | 深度推理，更严谨遵循设定，耗时较长 | 复杂情节设计、设定推演 |
| **极高** | 最大深度推理，输出最结构化，耗时最长 | 关键章节、需要严格一致性的内容 |

- **默认值**：全局默认使用「自动」，用户可在项目或会话中调整。
- **内部映射**：由系统根据用户选择的等级自动设置底层参数（如 `reasoning_effort`、`temperature`、`max_tokens` 等），不向用户展示具体 API 参数，也不提供不同模型 API 的预设映射编辑。

#### 1.2 交互设计

- 位置：AI 对话工作台顶部工具栏「模型设置」按钮（齿轮图标）。
- 面板内容：
  - **思维深度**：下拉选择或分段控件，选项为：无、自动、低、中等、高、极高。
  - **随机性（创意性）**：保留一个滑块（0~2），默认值 0.7，用户可独立调整。
  - **最大输出长度**：数字输入框，默认 2048。
- 保存时提示：**“设置将应用于后续消息，不影响已有消息。”**
- 设置生效于当前会话的后续消息；可在项目设置中设为默认，新会话继承。

#### 1.3 数据实体更新

- `Conversation` 增加字段：
  - `model_config` JSON，例如 `{"depth": "auto", "temperature": 0.7, "max_tokens": 2048}`
- `Project` 增加字段：
  - `default_model_config` JSON，默认 `{"depth": "auto", "temperature": 0.7, "max_tokens": 2048}`
- 全局设置中存储：
  - `global_default_model_config` JSON，默认 `{"depth": "auto"}`

### 2. 对话系统提示词自定义

#### 2.1 功能定义

- **多模板支持**：用户可以创建、编辑、删除多个系统提示词模板，并在对话会话中自由切换。
- **默认模板**：系统内置一个「自动」模板，作为全局默认。用户未调整时，所有新项目和新会话使用该模板。
- **模板作用范围**：模板可保存为全局模板（跨项目可用）或项目模板（仅当前项目可用）。会话可直接选择模板，也可在会话内临时编辑（不影响原模板）。
- **占位符变量**：支持在模板中插入变量，如 `{{KNOWLEDGE_BASE}}`、`{{CURRENT_CHAPTER}}`、`{{STYLE_CARD}}`，系统在发送请求时自动替换。

#### 2.2 交互设计

- 位置：与「模型设置」同一面板，或独立「提示词设置」标签页。
- 面板结构：

```
┌──────────────────────────────────────────────┐
│ 模型设置   提示词设置                          │
├──────────────────────────────────────────────┤
│ 当前会话模板：[自动模板 ▾]  [编辑] [新建]      │
│                                              │
│ 模板列表：                                    │
│  ● 自动模板（系统默认）                       │
│  ○ 我的古风模板                               │
│  ○ 第一人称悬疑模板                           │
│                                              │
│ 编辑区（多行文本编辑器，支持变量插入）         │
│ ┌──────────────────────────────────────────┐ │
│ │ 你是一位专业的中文小说写作助手...           │ │
│ └──────────────────────────────────────────┘ │
│ 插入变量：[知识库] [当前章节] [文风卡]        │
│ 作用范围：○ 仅本会话  ● 保存为项目模板  ○ 全局 │
│ [重置为默认] [保存]                           │
└──────────────────────────────────────────────┘
```

- 保存时提示：**“新设置将应用于后续消息，不影响已有消息。”**
- 会话内切换模板：在「当前会话模板」下拉中选择，立即生效于后续消息。
- 用户可点击「编辑」修改当前模板，若模板为系统默认，编辑后自动另存为自定义模板。

#### 2.3 数据实体更新

新增 `PromptTemplate` 表：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 模板唯一标识 |
| name | string | 模板名称 |
| content | TEXT | 系统提示词内容（可含占位符） |
| scope | enum | `global`（全局）或 `project`（项目） |
| project_id | string | 若为项目模板，关联项目 ID；全局模板此字段为空 |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

`Conversation` 增加字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `system_prompt_template_id` | string | 当前会话使用的系统提示词模板 ID（为空则继承项目或全局默认） |
| `system_prompt_override` | TEXT | 会话级临时覆盖内容（仅在用户临时编辑时使用） |

`Project` 增加字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `default_prompt_template_id` | string | 项目默认提示词模板 ID |

全局设置中增加：

| 字段 | 类型 | 说明 |
|------|------|------|
| `global_default_prompt_template_id` | string | 全局默认提示词模板 ID，默认指向「自动模板」 |

### 3. 更新后的页面结构（AI 对话工作台顶部）

```
顶部栏：
[项目选择器 ▾]  [新建对话]  [历史会话]  [⚙ 模型/提示词设置]
```

点击「⚙ 模型/提示词设置」打开抽屉面板，包含两个标签页：
- **模型设置**：思维深度等级、随机性、最大输出长度。
- **提示词设置**：模板选择与编辑、模板列表管理。

---

### 4. 补充说明

- **全局默认自动**：思维深度和系统提示词均默认使用「自动」；用户未做任何调整时，系统按自动策略处理。
- **提示语**：在所有相关保存操作后显示：“新设置将应用于后续消息，不影响已有消息。”
- **内部映射不透明**：思维深度等级由系统内部映射到 API 参数，用户无需关心具体数值，也无需针对不同模型 API 进行配置。
